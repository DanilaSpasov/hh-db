# Проект hh-db

## Описание

`hh-db` - учебное консольное приложение для работы с данными о компаниях и вакансиях в PostgreSQL.

При запуске программа:

1. читает вакансии из локального файла `data/hh_vacancies.json`;
2. группирует их по работодателям;
3. создаёт указанную в `.env` базу данных и таблицы `employers` и `vacancies`;
4. сохраняет компании и вакансии в PostgreSQL;
5. открывает консольное меню для выполнения запросов к базе данных.

Важно: текущий `main.py` не загружает данные с hh.ru. Он использует только локальный JSON-файл из проекта.

## Стек

- Python 3.14;
- PostgreSQL;
- Poetry;
- `psycopg2-binary` - подключение к PostgreSQL и выполнение SQL-запросов;
- `python-dotenv` - загрузка настроек подключения из `.env`;
- `requests` - HTTP-запросы в отдельном модуле `src/api.py`;
- `pytest` - запуск автоматических тестов;
- `pytest-cov` - подсчёт покрытия и создание HTML-отчёта.

## Данные

Файл `data/hh_vacancies.json` содержит 25 тестовых вакансий пяти компаний:

- Ozon Tech;
- Yandex;
- VK;
- Tinkoff;
- Sber.

Во время запуска эти данные преобразуются и сохраняются в две связанные таблицы:

- `employers` - работодатели;
- `vacancies` - вакансии, зарплаты и ссылки на страницы вакансий.

Если у зарплаты указаны обе границы `from` и `to`, в базу записывается
их среднее арифметическое. Если указана только одна граница, используется
её значение. Если зарплата или обе её границы отсутствуют, в базу
записывается `NULL`. Эту обработку выполняет функция `calculate_salary()`
из модуля `src/database.py`.

Модуль `src/api.py` умеет получать сведения о работодателях и их вакансиях через API hh.ru. В текущем сценарии он не импортируется и не вызывается из `main.py`: запуск приложения не обращается к API и не обновляет `data/hh_vacancies.json`.

## Подготовка PostgreSQL

Перед запуском должен быть установлен и запущен PostgreSQL.

Пользователь PostgreSQL, указанный в `.env`, должен:

- подключаться к служебной базе `postgres`;
- иметь право `CREATEDB`;
- иметь право удалить базу с именем из `DB_NAME`, если она уже существует.

Если база уже существует, пользователь должен быть её владельцем или суперпользователем PostgreSQL. Для локального учебного запуска проще всего использовать роль с достаточными правами, например локального суперпользователя PostgreSQL.

Каждый запуск `main.py` выполняет `DROP DATABASE IF EXISTS`, а затем `CREATE DATABASE` для базы, указанной в `DB_NAME`. Все ранее сохранённые данные в этой базе будут удалены. Не указывайте базу с важными данными.

## Установка

Для проекта требуются Python 3.14, Poetry и PostgreSQL.

Перейдите в корень проекта и установите зависимости:

```
poetry install
```

Откройте `.env` и укажите свои параметры подключения:

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hh_db
DB_USER=имя_пользователя_postgresql
DB_PASSWORD=пароль_пользователя_postgresql
```

Не добавляйте `.env` в Git и не публикуйте реальные логины и пароли.

## Запуск

Запускайте программу из корня проекта, потому что путь к JSON-файлу задан относительно текущего каталога:

```
poetry run python main.py
```

После пересоздания базы, создания таблиц и загрузки данных откроется консольное меню.

## Консольное меню

### 1. Показать компании и количество вакансий

Выводит каждую компанию и количество связанных с ней вакансий.

### 2. Показать все вакансии

Выводит название компании, название вакансии, рассчитанную зарплату и ссылку на вакансию.

### 3. Показать среднюю зарплату

Рассчитывает среднюю зарплату по всем вакансиям в таблице `vacancies` и выводит результат в рублях.

### 4. Показать вакансии с зарплатой выше средней

Выводит вакансии, зарплата которых выше общего среднего значения. Результат сортируется по зарплате от большей к меньшей.

### 5. Найти вакансии по ключевому слову

Запрашивает строку и ищет её в названии вакансии без учёта регистра. Можно вводить как полное название, так и его часть, например `Python` или `аналитик`.

### 6. Выйти

Завершает работу консольного приложения.

При вводе другого значения программа сообщает об ошибке и снова показывает меню.

## Тестирование

В проекте реализовано 23 автоматических теста. Они проверяют:

- получение работодателей и всех страниц вакансий через API hh.ru;
- чтение настроек подключения из переменных окружения;
- создание базы данных и таблиц;
- расчёт и сохранение зарплаты, включая значения `None`;
- SQL-запросы класса `DBManager`;
- загрузку и группировку вакансий из JSON-файла;
- вывод вакансий и работу консольного меню.


Для запуска всех тестов выполните:

```
poetry run pytest
```

Для запуска тестов с подсчётом покрытия и создания HTML-отчёта выполните:

```
poetry run pytest --cov=src --cov=main --cov-report=html
```

Все 23 теста проходят, а общее покрытие файлов `main.py` и каталога `src` составляет 99%.
